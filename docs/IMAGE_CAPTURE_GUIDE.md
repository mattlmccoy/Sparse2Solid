# Image Capture Guide

This guide describes what to photograph when you want a clean architectural model from a sparse reference set.

## Minimum Workable Set

For a regular facade, aim for:

- 1 straight-on main elevation
- 1 front-left oblique
- 1 front-right oblique
- 1 side elevation
- 1 rear or terrace/back view
- 1 roofline detail
- 3-5 closeups of repeated units
- 1 context/scale image

That is roughly 10-12 images. It can work, but it leaves little margin.

## Strong Set

For a high-quality model, aim for 20-35 images:

- 3 main elevation images with different lenses/distances
- 3 left obliques
- 3 right obliques
- 2 side views per side if available
- 2 rear/terrace views
- 3 roofline/parapet/awning views
- 6-10 detail closeups
- 2 wide context/scale views

## What Makes an Image Useful

Useful images answer one or more questions:

- How many repeated bays exist?
- How wide is one bay relative to the full facade?
- How deep are columns, arches, doors, and lamps?
- Where does the roof start relative to the facade?
- Is there a second level, balcony, terrace, or parapet?
- What touches the ground?
- Which details repeat and which details are unique?

## What Makes an Image Less Useful

- Severe blur
- Cropped roof or base
- Extreme wide-angle distortion
- Night images with blown highlights
- Decorations hiding permanent architecture
- Many duplicate photos from nearly the same position
- Closeups with no context when scale is unknown

## Practical Advice

- Take one "boring" orthographic shot. It is extremely useful.
- Take oblique shots from both sides.
- Capture ground contact for everything freestanding.
- Get a roofline view if possible. Roofs are commonly underconstrained.
- If something repeats, photograph one instance close up and the whole row wide.
- If a dimension is known, write it down immediately.
- Keep real photos and synthetic/generated references in separate folders.
