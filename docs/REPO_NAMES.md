# Repo Name Ideas

Good names for this project should signal sparse views, model forging, and clean architectural structure.

## Strong Candidates

- `sparse2solid`
- `Sparse2Solid`
- `viewforge3d`
- `sparse-to-structure`
- `image-to-architecture`
- `archforge3d`
- `facade-forge`
- `view-to-venue`
- `structure-from-views`
- `component-recon`
- `model-from-views`
- `venueforge`

## Chosen Name

`Sparse2Solid`

Why:

- It directly signals sparse 2D image coverage becoming solid 3D geometry.
- It is short and memorable.
- It does not imply hundreds of photogrammetry images are required.
- It leaves room for future AI, CAD, and review tooling.
- It avoids overclaiming fully automatic reconstruction.
