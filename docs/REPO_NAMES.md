# Repo Name Ideas

Good names for this project should signal sparse views, model forging, and clean architectural structure.

## Strong Candidates

- `viewforge3d`
- `sparse-to-structure`
- `image-to-architecture`
- `archforge3d`
- `facade-forge`
- `view-to-venue`
- `structure-from-views`
- `component-recon`
- `model-from-views`
- `venueforge`

## Chosen Name

`viewforge3d`

Why:

- It is short.
- It is not tied to one building type.
- It suggests craft rather than magic.
- It leaves room for future AI, CAD, and review tooling.
- It avoids overclaiming full automatic reconstruction.
